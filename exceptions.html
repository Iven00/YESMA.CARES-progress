異常／需你處理

權威資料在 Google Sheet 工作表 PO_Actions（OPEN）。 由程式 PM／SM 排程寫入；你處理後把該列改 DONE。

正式異常頁（Apps Script Web App）

打通 Sheet 並部署 Web App 後，把 URL 填進下方（或改本檔連結）。

尚未設定 webapp_url — 見試算表 Meta 或通道說明

你怎麼用
  1. 排程每小時（或選單「立即排程一輪」）掃描票 → 寫入 PO_Actions
  2. 開 Web App 異常頁，手動刷新
  3. 在 Sheet 填 po_resolution，status=DONE
